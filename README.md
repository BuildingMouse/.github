# BuildingMouse 🐭

Hi, I'm Mouse! I create open-source tools for computational geometry,
3D geometry, and in-game housing systems.

My main project, Mesh to Housing, explores ways to translate complex
3D models into sparse construction guides that can be recreated within
the object and placement constraints of game housing systems.

## Mesh to Housing

I'm developing methods for reducing complex 3D geometry while preserving
the features that make the original model recognizable.

Current and planned areas include:
- geometry-aware point reduction
- user-defined focal points
- topology-preserving simplification
- visual feature detection
- ML-assisted point selection
- game-specific integrations

Planned integrations currently include World of Warcraft Housing and The Elder Scrolls Online Housing.
